# Передбачення: правила Markdown

## Передбачення 1. Два рядки без порожнього рядка між ними

```
Перший рядок
Другий рядок
```

**Передбачення:** перегляд покаже два окремі рядки, як у файлі.

**Показав:** один рядок — `Перший рядок Другий рядок`. Я не вгадав, бо в Markdown один перенос рядка вважається пробілом усередині того самого абзацу. Новий абзац починається лише після порожнього рядка, а щоб розірвати рядок без абзацу, треба поставити в кінці два пробіли або `\`.

## Передбачення 2. Список із трьох `1.`

```
1. один
1. два
1. три
```

**Передбачення:** три пункти з номером 1.

**Показав:** 1, 2, 3. Я не вгадав, бо Markdown бере з першого пункту лише стартовий номер, а далі нумерує сам. Тому зручно скрізь писати `1.`: при додаванні пунктів нічого не треба перенумеровувати.

## Передбачення 3. `Це **жирний ** текст`

**Передбачення:** слово «жирний» буде жирним.

**Показав:** не жирне, у тексті видно зірочки — `Це **жирний ** текст`. Я не вгадав, бо закривальні `**` не можуть стояти одразу після пробілу. Markdown їх не вважає кінцем виділення, і обидві пари зірочок лишаються звичайним текстом.

## Передбачення 4. Таблиця без рядка з дефісами

```
| А | Б |
| 1 | 2 |
```

**Передбачення:** буде таблиця 2×2.

**Показав:** не таблиця, а звичайний абзац із вертикальними рисками. Я не вгадав, бо Markdown розпізнає таблицю тільки тоді, коли одразу під заголовком стоїть рядок-роздільник `|---|---|`.
