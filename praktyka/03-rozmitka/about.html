Про мене

Мене звати Назар, я студент групи 316-пр. Мені подобається розбиратися, як влаштовані програми й сервери «під капотом». У вільний час налаштовую власні невеликі проєкти й експериментую з новими інструментами. Найбільше ціную в коді простоту й зрозумілість.

Мови й інструменти, з якими я вже працював:

  • Python
  • Git і GitHub
  • Markdown і HTML
  • SQL (SQLite)

Навчання

Зараз я на третьому курсі й вивчаю спеціалізовані мови програмування. На курсі ми розбираємо предметні мови: Git, розмітку, конфігурацію, регулярні вирази й SQL. Кожну роботу я складаю у свій репозиторій, тож уся історія навчання видна в комітах. Найкориснішою темою поки що вважаю Git, бо він потрібен у кожному проєкті.

До кінця семестру хочу виконати всі практичні роботи й навчитися автоматично перевіряти свій код через GitHub Actions. Далі планую глибше вивчити бази даних і бекенд-розробку. Мета на рік — зробити власний повноцінний проєкт і викласти його відкрито. Усі мої роботи можна переглянути в моєму репозиторії.
