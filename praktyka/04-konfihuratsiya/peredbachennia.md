# Передбачення: що Python прочитає з pastky.yaml

| Ключ | Моє передбачення: значення і тип | Показав perevir.py |
|---|---|---|
| svitlo | `'off'`, рядок | `False`, логічне |
| pochatok | `'2026-09-28'`, рядок | `datetime.date(2026, 9, 28)`, дата |
| kod_dostupu | `10`, ціле число (нуль на початку відкинеться) | `8`, ціле число |
| limit | `1000.0`, дробове число | `'1e3'`, рядок |
| port | `'0x1F90'`, рядок | `8080`, ціле число |
| komentar | `'~'`, рядок | `None`, порожнє |

Найбільше здивувала пастка `kod_dostupu: 010`. PyYAML реалізує стару версію YAML 1.1, де число з нулем на початку вважається вісімковим, тож код доступу `010` непомітно перетворився на `8`. Так само `off` стало `False`, а `~` — `None`, тоді як `1e3` без крапки, навпаки, лишилось рядком. Обійти всі ці пастки просто: значення, які мають бути рядками (коди, версії, `yes/no/on/off`), треба брати в лапки, наприклад `kod_dostupu: "010"`, і перевіряти, що реально прочитав Python, а не онлайн-конвертер.
