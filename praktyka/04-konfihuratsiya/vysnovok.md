# Висновок: вибір формату конфігурації

Для мого бота з розкладом я обрав би TOML. Як і YAML, він підтримує коментарі й легко читається людиною, тож викладач чи адміністратор без досвіду програмування зможе змінити порт або додати групу. Але на відміну від YAML, у TOML рядки завжди в лапках, тому пастки на зразок `010 → 8` чи `off → False` тут неможливі: тип видно одразу. JSON я лишив би для обміну даними між програмами, бо він не має коментарів і ламається від однієї зайвої коми. До того ж TOML читається вбудованим модулем Python `tomllib`, без додаткових бібліотек.
